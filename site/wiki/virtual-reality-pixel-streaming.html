    Virtual reality streaming

    Stream a VR application to a headset over the web. The headset's browser opens a link; the rendering happens on Eagle 3D Streaming's GPU machines, exactly as it does for any other app.

    There is a live example you can open in a headset right now: the VR demo.

    Use Unreal Engine 5.5. Not 5.4, not 5.6. Other versions have known faults in VR streaming — 360° view distortion and double vision — that nothing on our side can correct. Check this first: everything else you do is wasted if the engine version is wrong.

    What is different about VR

    Most of it is the same as any other app: build it, package it for Windows, upload the ZIP, open the link. Three things are not.

    DifferenceWhat it means for you
    The engine version is fixed Unreal 5.5. Anything else distorts the view or doubles it.
    OpenXR must be disabled Counter-intuitive, and easy to get backwards. It is switched off, not on.
    The VR template spawns in the floor Unreal's own template puts the player through the ground at start. There is a fix, and you will need it.

    What we have tested

    Known good, and known unknown

    • Tested: Oculus Quest 2 and Quest 3.
    • Expected to work, untested: the original Quest, and other headsets with a modern browser. If yours does not, tell us — that is how this list grows.
    • Not tested at all: Linux builds in VR. Compatibility and performance there are unverified, so treat it as unsupported rather than as likely to work.

    The path

    1. Build and configure the project

      Create a VR project, enable Pixel Streaming, disable OpenXR, fix the player start, and package it. Setting up a VR project covers all of it.

    2. Test it locally, with a headset

      Against Epic's own signalling server, before it goes near the platform. A VR fault is far harder to read through a stream than on your own machine, and this step removes a whole class of confusion later.

    3. Upload it like any other app

      Nothing VR-specific: the same ZIP, the same Control Panel. See uploading from the Control Panel.

    4. Open the link in the headset's browser

      Each app has its own streaming URL, of the form connector.eagle3dstreaming.com/v5/<owner>/<app>/<config>. Open it in the headset's browser — there is nothing to install on the device.
