Prerequisites

Set up the E3DS Streaming Agent. Follow this document.

Instructions

  1. Open Task Scheduler from the start menu.

  2. Create a task from the right side panel.

  1. Enter a name for the task. From the Triggers Tab, select “At log on“

  2. Select “At log on of any user“.

  1. Go to the Action Tab and click on ‘'new’'.

  2. Browse and select the EL.exe file.

  3. In the “Start in“ box add the folder path where the EL.exe exist.

  1. Click OK

Now the E3DS Streaming Agent will Auto-Start every time you log into Windows!
