Change a project, build a patch from it, prove the patch works locally, then upload it.

Before you start

Both launch profiles configured. If you want a project already set up for this, there is a patch-prepared project to start from.

  1. Make your change in Unreal — edit the level or a Blueprint, add an object, whatever the update is — and save everything.

  2. Build the patch. Open Platforms → Project Launcher, select your patch profile, and click Launch.

  3. Collect the file. It appears at:

    Saved\StagedBuilds\Windows\[ProjectName]\Content\Paks

Test it locally first

Copy the generated .pak into the Content\Paks folder of your base game, and run the base game. Your change should be there.

This is the step worth not skipping

It takes a minute and it separates two very different problems: a patch that was built wrong, and a patch that was uploaded wrong. Finding out after upload leaves you guessing between them.

Upload it

Upload the base game normally, through the Control Panel. The patch goes to a separate URL you construct yourself — the patch upload URL.

Then play the app online and confirm the change is live.

If the app runs but shows the old content, the patch is not being picked up. Check the naming and the ordering — patches apply in sequence, and one that sorts before an existing patch will be overridden by it rather than ignored outright.
