Learn to create a Streaming URL from the Control Panel.

Prerequisites

  1. Access to the Control Panel.

  2. Eagle 3D’s User Account.

  3. At least one App Uploaded

Instructions

Step 1. Sign In to the Control Panel

Login with your information.

Step 2. Select your App

Step 3. Generate a Streaming link

1. Click ‘'Create New Stream link’'

2. One Streaming Link is created

3. Click Create New Stream link every time you want to generate more links

Tip : This Feature allows to create a different Config for each Streaming Link.

Refer to this document to create Configs.
