The E3DS Automation Tools plugin packages your project, compresses it and uploads it in one action, without leaving the Unreal Editor. It replaces the package–zip–browse–upload sequence you would otherwise repeat every time.

It produces exactly the same result as uploading from the Control Panel — it does not unlock anything. What it saves is the repetition, which is why it is worth setting up once you are uploading regularly rather than on your very first attempt.

Before you begin

  • Unreal Engine 5.1 or newer, with your project open.
  • 7-Zip installed. The plugin uses it to compress the build, and compresses harder than a plain ZIP, which is most of the time saved on upload.
  • An Eagle 3D Streaming account, for the API key in step 3.

Package your project by hand once first. Packaging failures are Unreal's, not ours, and they are far easier to read in Unreal's own output than through an automated run. Once a manual package succeeds, you know any later failure belongs to the upload rather than to the build.

1. Install the plugin

Three ways to get it. They install the same plugin.

Recommended

Fab Marketplace

Through the Epic Games Launcher. Updates arrive the way every other marketplace plugin's do, and there is no folder to name correctly.

Download from GitHub

A ZIP you extract into your project. Use it when you cannot install through the Launcher.

Clone from GitHub

Same files, kept under git, so you can pull updates. Use it if you track the plugin's changes.

From the Fab Marketplace

Open the Epic Games Launcher, go to Unreal Engine › Fab and press Start exploring, which opens Fab in your browser. Search for E3DS Automation Tools and press Add to My Library. Back in the Launcher, go to Unreal Engine › Library, refresh the Fab library, and install the plugin for your engine version.

From GitHub, as a download or a clone

Both routes put the plugin in the same place. In your Unreal project folder, create a Plugins folder if there is not one already, then either download the ZIP and extract it there, or clone the repository into it.

The folder must be named E3DSAutomationTools. Both GitHub and a clone give it a different name — a ZIP extracts to something like E3DSAutomationTools-master. Rename it. Unreal finds plugins by folder name, so a folder named anything else is a plugin that silently does not exist.

2. Enable Pixel Streaming

Separate from the plugin above, and required either way: a build without it cannot stream.

  1. Open Edit › Plugins

  2. Enable the Pixel Streaming plugin

  3. Restart the editor

    The plugin is not active until you do.

3. Configure the plugin

Go to Edit › Project Settings, and under Plugins choose E3DS Automation Tools Settings. Everything below lives on that one page, and you set it once per project.

  1. Download the E3DS automation executable

    Press Download E3DS Automation Tool Executable, then point Path to E3DS Automation Executable at the EL_AT.exe you just downloaded.

  2. Point it at 7-Zip

    Set Path to 7z.exe to your 7-Zip installation.

  3. Get and paste your API key

    Press Get E3DS API Key, which opens the Control Panel; sign in if you are asked. Copy the generated key and paste it into the API Key field. This is what ties the upload to your account, so treat it like a password.

  4. Name the streaming application

    Letters and numbers only — no dots, no spaces.

    Reusing a name is not a mistake, it is how you publish an update. Uploading under a name you have used before creates a new version of that application rather than a second application. Use a new name only when you mean a genuinely separate app.

  5. Choose a packaging mode

    Development packages more slowly and shows the output log while it works. Shipping is faster and shows nothing. Use Development until an upload has succeeded once — when something fails, that log is the only thing that will tell you why.

  6. Leave "Build Dedicated Server App" unticked

    It is for multiplayer projects with a dedicated server, and produces a build that will not stream on its own.

    Check it rather than assume it. It is off by default with an engine installed from the Epic Games Launcher, but on by default in the Epic GitHub build and in the E3DS custom engine — so whether you need to change anything depends on where your Unreal came from.

  7. Optionally open the stream when the upload finishes

    Launch Streaming App URL on Completion opens the stream in your browser as soon as the upload completes, so you are not watching for it.

4. Push it to the cloud

Save everything first. Unsaved maps, unsaved blueprints and newly imported assets are not included in the package. With the Fab build of the plugin you get a popup telling you so; save everything, then start again.

Then press Launch E3DS Automation Tool. Packaging runs first, then compression, then the upload.

If your connection drops, the upload fails and must be run again. It does not resume. On a slow or unreliable connection this is the step to watch, because everything before it has to be redone.

You will know it worked when

The tool reports the upload finished, and the application appears in your Control Panel — as a new version, if you reused the name.

5. Stream it

Identical to the Control Panel route from here: open the application, press Create New Stream Link, then Play App, wait for a machine, and press play.
