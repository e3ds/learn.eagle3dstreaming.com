A Node.js package that uploads a packaged build, registers it, and waits for the stream test — so a deployment can be a step in a script rather than a person at a browser.

Two ways to automate an upload

The Automation Tools plugin works from inside Unreal, which suits a developer packaging by hand. The Automation Kit works from a script, which is what you want in a CI/CD pipeline where nobody is watching.

Install

npm install e3ds-automation-kit

The package is on npm.

The script

const { uploadStreamingApp } = require("e3ds-automation-kit");

(async () => {
  try {
    await uploadStreamingApp(
      "../../Downloads/tinyApp.zip",  // path to the .zip
      process.env.E3DS_API_KEY,       // your API key
      "MyStreamingApp"                // app name
    );
    console.log("Upload completed successfully!");
  } catch (err) {
    console.error("Upload failed:", err.message);
  }
})();
node index.js

Which then validates the path, requests a signed upload URL, uploads with progress, and polls until the stream test finishes.

Do not hard-code the API key. It authorises uploads to your account, and a script with a key in it ends up in version control. Read it from an environment variable, as above — particularly in CI, where the key belongs in the pipeline's secret store.

The path argument

Most failures here are the path, so it is worth getting right first time. It must point at the .zip file itself, not the folder holding it and not the project directory.

FormExampleWorks
Relative to where you run node"../../Downloads/tinyApp.zip"Yes
Windows, forward slashes"C:/Users/USER/Downloads/tinyApp.zip"Yes — the easiest on Windows
Windows, escaped backslashes"C:\Users\USER\Downloads\tinyApp.zip"Yes
macOS or Linux"/Users/USER/Downloads/tinyApp.zip"Yes
Windows, single backslashes"C:\Users\USER\Downloads\tinyApp.zip"No — JavaScript reads \ as an escape character
A folder"C:/Users/USER/Downloads/"No — must end in .zip

The app name argument

Letters, numbers and underscores only. No spaces, no hyphens, no dots, no other punctuation. 

"MyStreamingApp"    // fine
"My_App_01"         // fine
"app123"            // fine

"My Streaming App"  // space
"My-App"            // hyphen
"My@App"            // symbol
"My.App"            // dot

This is the name that appears in your Control Panel once the upload lands.
