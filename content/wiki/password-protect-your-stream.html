This guide explains how to secure your Eagle 3D Streaming application with a password from the Control Panel.

When Password Protect Stream is enabled, users must enter the correct password before they can access the streamed application.

Follow the steps below:

Step 1. Sign In to the Control Panel

Sign in to the Eagle 3D Streaming Control Panel using your account credentials.

Step 2. Select your App

From the Control Panel, select the app for which you want to enable password protection.

Step 3. Generate a Streaming Link

Generate a streaming link for your app.

For more details check the doc: Generate a Streaming Link for your App.

Step 4. Create a Config

Create a config for the streaming link.

For more details check the doc: Create a Config for each Streaming Link.

Step 5. Edit the Config

Open the config settings for the streaming link.

For more details check the doc: Edit your Config.

Step 6. Enable Password Protect Stream

In the config settings, enable the Password Protect Stream option.

This feature allows you to protect the streaming link with a password.

Step 7. Set the Password

Step 8. Click Save

After entering the password, click Save.

Step 9. Click Save Again

Click Save again to confirm and apply the config changes.

Step 10. Test the Password-Protected Stream

To confirm that password protection is working, test the stream using the configured streaming link.

1. Click Play App

Click Play App to open the stream with the selected config.

Make sure you are using the config with the password-protected config.

2. Enter the Password

When the stream opens, you will be asked to enter the password.

Type the correct password in the password field.

3. Click Submit

Click Submit to continue.

If the password is correct, the stream will start.

If the password is incorrect, the user will not be able to access the stream.

Incorrect Password

If the user enters the wrong password, access to the stream will be denied.

Password Timeout

If the user does not enter the password within 1 minute, the password page will expire and the user will see the timeout page.

Forgot the Password

If you forget the password, you can check or update it from the config settings.

Go to:

Control Panel → Click on the App → Edit Config → Common → Password Protect Stream

From there, you can view or update the password.

Troubleshooting

Issue

Possible Reason

Solution

Password page is not showing

Password Protect Stream is not enabled in the selected config

Go to Edit Config → Common → Password Protect Stream, enable the option, enter the password, and save the config.

Password is not working

The user may be entering the wrong password, or the password was changed in the config

Check the password from Control Panel → Click on the App → Edit Config → Common → Password Protect Stream and try again.

Stream opens without asking for a password

The user may be using a different streaming link or config where password protection is not enabled

Make sure you are using the correct streaming link with the password-protected config.

Password page expires

The password was not entered within 1 minute

Refresh the stream page and enter the password again within the allowed time.
