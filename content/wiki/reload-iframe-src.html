Force the stream to reconnect from scratch by clearing and restoring the iframe's src.

This is the child of Embed with an iframe — use it once you already have a working iframe embed and want a "restart" control on top of it.

Why you cannot just re-set the src

Setting iframe.src back to the URL it already has does nothing. The browser compares the new value to the current one, sees no change, and skips the reload entirely — even though you clearly intended to refresh the frame.

Clear it first

Point the iframe at about:blank first, then restore the original URL a moment later. The blank navigation forces the browser to actually tear down the old frame — and its session — before the real URL loads again: 

function restartIframe() {
  const iframe = document.getElementById("iframe_1");
  const originalSrc = "YOUR_STREAM_URL";

  iframe.src = "about:blank";

  // small delay so the browser tears down the old frame
  // before the real URL loads again
  setTimeout(() => {
    iframe.src = originalSrc;
  }, 50);
}

The delay matters. Restoring the URL in the same tick as the about:blank assignment is unreliable — some browsers coalesce the two navigations into one. A short setTimeout (50–100ms) gives the teardown time to actually happen first.

Wire it to a button

A restart button needs to sit visually above the iframe, not behind it: 

<button
  style="position: absolute; top: 16px; left: 16px; z-index: 10;"
  onclick="restartIframe()"
>
  Restart
</button>

The iframe itself should not carry a z-index higher than the button's, or clicks on the button will be captured by the frame instead.

You will know it worked when

Pressing the button drops the current session and starts a fresh queue — the same as if the viewer had reloaded the whole page, but without losing anything else on it.
