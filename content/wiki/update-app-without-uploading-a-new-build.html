This guide explains how to update an application without uploading a new build through the Eagle 3D Streaming Control Panel.

This method uses the E3DS Streaming Agent and replaces the application files directly on the machine where the application is stored.

This can be useful when, for example, you have security requirements and prefer not to upload the actual application build to the Control Panel.

Important: Before using this method, you must first upload an application to your E3DS account. This application creates the required application entry, configuration, and local directory when used with the E3DS Streaming Agent.

Resources

  • E3DS Streaming Agent: Download E3DS Streaming Agent

  • Streaming Agent installation guide: Setting Up E3DS Streaming Agent

Follow the steps below:

Step 1. Upload an Application to the Control Panel

First, upload an application to the E3DS Control Panel.

If you do not want to upload your actual application build due to security requirements, you can upload a small placeholder application instead.

However, the application name should be the same name you want to use for your actual application.

For example, if your actual application is named:

MyApp

Upload the placeholder application using the name:

MyApp

This is important because the Streaming Agent uses the application name when creating the local application directory.

Step 2. Set Up the E3DS Streaming Agent

Install and configure the E3DS Streaming Agent on the machine where you want to host the application.

Follow the installation guide: Setting Up E3DS Streaming Agent

Step 3. After completing the setup, stream the application at least one time.

This allows the Streaming Agent to download and prepare the application files in the local application directory.

Step 4. Locate the Application Directory

After streaming the application, navigate to the local application directory:

C:\e3ds_streaming_apps\<username>\<application-name>\1

For example:

C:\e3ds_streaming_apps\mwoji\MyApp\1

Where:

  • mwoji is the E3DS username.

  • MyApp is the application name.

  • 1 represents the application version directory.

Step 5. Back Up and Remove the Existing App Files

Before making any changes, we recommend creating a backup of the existing application directory.

Then remove the existing application files from:

C:\e3ds_streaming_apps\<username>\<application-name>\1

Keep the .meta folder generated by the E3DS Streaming Agent.

Step 6. Copy the Updated Application Build

Copy all files from your updated application build.

Paste them into the same application directory:

C:\e3ds_streaming_apps\<username>\<application-name>\1

For example:

C:\e3ds_streaming_apps\mwoji\MyApp\1

Make sure the complete packaged application is copied, including all required folders and files.

Step 7. Keep the Executable Name Consistent

The executable file name must match the executable name configured for the original application.

For example, if the original application executable was:

MyApp.exe

The updated application's executable must also be named:

MyApp.exe

If your new build has a different executable name, rename it to match the original executable name.

Step 8. Start Streaming the Application

Once the updated files are in place, start the application using the same streaming URL you used previously.

There is no need to create a new application or upload another build through the Control Panel.

For example:

Your existing application URL

Open the URL in your browser and start a new streaming session.

The E3DS Streaming Agent should now launch the updated application files.

Step 9. Verify the Updated App

Open the application URL and verify that the new version is running correctly.

Even though the application URL and application entry remain the same, the content streamed to the browser should now come from your updated local build.

Updating the Application Again

Whenever you need to update the application in the future, repeat the following process:

  1. Stop any active application sessions if necessary.

  2. Navigate to:

C:\e3ds_streaming_apps\<username>\<application-name>\1

  1. Back up the current files.

  2. Remove the old application build files while keeping the required E3DS .meta folder.

  3. Copy the new packaged application files into the directory.

  4. Ensure the .exe file name matches the executable configured for the application.

  5. Start a new streaming session using the existing application URL.

  6. Verify that the updated application launches correctly.

Important Notes

  • This method updates the application files directly on the machine running the E3DS Streaming Agent.

  • The application must first be uploaded in the E3DS Control Panel.

  • Stream the initially uploaded application at least once so that the local application directory is created.

  • Always create a backup before replacing application files.

  • Copy the complete packaged build, not only the .exe file.

  • Keep the application directory structure intact.

  • Do not delete the E3DS metadata folder required by the Streaming Agent.

  • The executable name must remain consistent with the executable configured for the application.

  • Test the updated application locally before replacing the production files whenever possible.

Troubleshooting

Issue

Possible Cause

Solution

The updated application does not appear when streaming

The new build was copied to the wrong folder.

Verify that the files were copied to the correct application version folder: C:\e3ds_streaming_apps\<username>\<app_name>\1

The old application is still streaming

The old application files were not completely replaced. Exe was not renamed.

  • Stop the application/session, remove the previous build files except for the required metadata file, then copy the updated build again.

  • Rename the exe same as previous exe file

The application fails to launch after replacing the files

The main .exe file name does not match the original uploaded application's executable name.

Rename the new application's .exe file to exactly match the previous .exe file name.

The application closes immediately

The updated build may have missing files, dependencies, or an incorrect folder structure.

Test the updated application locally by running the .exe before copying it to the E3DS Streaming Agent folder. Make sure all packaged files are included.

The streaming URL does not work

The application may not have been streamed successfully through the E3DS Streaming Agent.

Make sure the Streaming Agent is running correctly and launch the application through the agent before testing the streaming URL.

A different application starts than expected

The files were copied into the wrong application folder or version folder.

Double-check the <username>, <app_name>, and version folder before replacing any files.

The meta folder was deleted

Required application meta folder was accidentally removed.

Do not delete the meta folder when replacing the application build. If it has already been deleted, restore the original application folder by streaming or setting up the application again before replacing the build.

The application works after replacement but stops working after another update

Files from the previous build may still remain and conflict with the new build.

For each update, remove the old application files while keeping the required meta folder then copy the complete new build.

The Streaming Agent does not detect the updated files

The application may still be running or the agent may be using the previous process.

Stop the running application and session, then restart the Streaming Agent if necessary and start a new streaming session.
