Send the viewer to a web page from inside your app — either in a new tab, leaving the stream running, or in the current one, ending it.

NodeEffectThe stream
E3DS Open URL Opens the address in a new tab. Keeps running. The viewer comes back to it.
Redirect To Navigates the current tab away. Ends. There is nothing to come back to.
Choose by whether they are finished

A spec sheet, a product page, a form to fill in — open a new tab, so the configuration they built is still there afterwards. Redirect only at a genuine end point, such as handing off to a checkout, because it discards the session and everything in it.

Opening a new tab

  1. Place BP_E3DS_PS_Actor from the plugin content into your level.

  2. From any actor, call E3DS Open URL and put the address in Url To Open.

Other plugins also ship a node called "Open URL". Picking the wrong one produces a Blueprint that compiles cleanly and does nothing when streamed. Hover the node before wiring it — the tooltip must say Target is BPFL E3DS PS Functions.

Redirecting the current tab

  1. Place an E3DS_PS_actor in the level you are streaming.

  2. In the Level Blueprint, add your trigger — the demo uses the 9 key — drag from its Pressed pin and add Redirect To. Put the full address in Url To Redirect To, then compile and save.

Without the plugin

Both nodes wrap a message you can send yourself. Add a PixelStreamingInput component to an actor and send the string with Send Pixel Streaming Response: 

{"cmd":"launchUrl","value":"https://www.eagle3dstreaming.com"}
{"cmd":"redirectTo","value":"https://www.eagle3dstreaming.com"}

The component only goes on an Actor. Actors, Pawns, Characters and Player Controllers can hold components; Widgets, GameModes and Level Blueprints cannot. And the actor must actually exist in the level — a Blueprint class that is never placed or spawned sends nothing.
