Passing values into your app

Two ways, and the difference is who decides the value.

Set byUse it when
Parameters to pass to app You, in the configuration The value is the same for everyone opening this link.
Append parameters to URL Whoever builds the link The value differs per visitor — a customer name, a starting scene.

Appending must be enabled in the configuration before a URL parameter will reach your app. With it off, the parameter is simply ignored — the stream runs, your value never arrives, and nothing reports a problem.

A URL parameter is not authentication. Appending an email address or a user id identifies who says they are opening the stream. Anyone can edit a URL, so treat these values as a convenience, never as proof — if access must be restricted, put a real login or a password in front of it.

Console commands at launch

Console CMDs to Pass to Unreal App runs Unreal console commands as the session starts — the same commands you would type into the in-editor console, applied automatically to every session on this configuration.

This is where per-app engine tuning belongs: a resolution scale, a quality setting, anything you would otherwise ask every viewer to set for themselves.

Region

Select region decides which part of the world serves the stream. Pick the one nearest your viewers — distance is latency, and latency is the thing people describe as "laggy" regardless of frame rate.

After launching, the Info button in the stream reports which region actually served it. Worth checking rather than assuming, particularly after changing the setting.

Getting the logs

Three separate ways to see what Unreal said, and they suit different moments.

SettingWhere the log goesBest for
Print UE log in browser console The browser's developer console, live Watching a problem as it happens, on your own machine.
Auto download UE crash log A file on the viewer's device, on crash A crash you can reproduce, where you have the device.
Email log on crash An address you choose Crashes you are not present for — a customer's session, an overnight event.

Turn on the email option before you need it. It is the only one of the three that works when the crash happens to somebody else, somewhere else — which is when the log is hardest to get and most worth having.

Predefined streaming quality

Sets the quality a session starts at, rather than leaving it to be negotiated. Useful when you know your audience's conditions — a venue with good wired network, or an event where you would rather have a steady picture than the best possible one.
