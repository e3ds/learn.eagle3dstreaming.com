Steps to secure the Streaming URL.

Prerequisites

  1. Access to the Control Panel.

  2. Eagle 3D’s User Account.

  3. At least one App Uploaded.

Instructions

  1. Use your log in credentials to sign in to the Control Panel.

  1. Under Applications, select your App.

  1. Create a new Streaming Link or use an already created one.

To generate a new Streaming link, follow this guide.

  1. Create a Config or use an existent one from the list.

To create a new Config, see this document.

  1. Click Edit Config.

  1. Toggle on Anonymize URL and click save

The URL structure will be replaced with anonymous character strings.

For example:
