In this document we will guide you how you can use Remote Control Unreal Editor Plugin.

The Remote Control Unreal Editor Plugin allows you to access and control your Unreal Editor remotely from any browser using Pixel Streaming.

This plugin completely automates the remote-editing workflow by:

  • Launching the remote editor streaming session automatically

  • Providing secure access via any browser

  • Enabling real-time editor control from any device

With a single click, you can start a streaming-enabled Unreal Editor session—no manual setup required.

Video Preview

Supported Unreal Engine Versions

Unreal Engine 5.3 – 5.8

Installation

  1. Download and install the plugin from FAB Marketplace.

  2. Restart Unreal Engine after installation.

Follow the steps below:

Step 1. Open Your Project

Step 2. From the Plugins section, search for Unreal Editor Remote Control

Step 3. Enable the plugin and restart the Unreal Editor

Step 4. Click “Yes” to apply the changes

Step 5. Open the Remote Control Unreal Editor dropdown menu

Step 6. Allow Remote Control

Enable Allow Remote Control.

By default, the plugin will:

  • Automatically start the stream

  • Automatically open your browser

  • Launch the remote editor session

Disable Auto-Open Browser

If you prefer to start the stream manually, disable:

Automatically Open Browser on Stream Start

You can also manually open the session

Copy the generated URL and paste it into your browser.

Step 7. Control the Unreal Editor Remotely

Once the session starts, you can fully control the Unreal Editor from any device with a browser.

Step 8. Stopping Remote Control

To end the session:

  1. Open the Remote Control Unreal Editor dropdown

  2. Click Stop Remote Control

This will stop streaming and close the active browser session.

Use Cases

  • Remote Unreal Editor access without manual server setup

  • Cloud-based development, debugging, or iteration

  • Real-time editor presentations and walkthroughs

  • Multi-device access to your editor from anywhere

  • Allow teammates or clients to review content remotely

Troubleshooting

Issue

Possible Cause

Solution

Browser doesn’t open

“Automatically Open Browser” unchecked

Enable the checkbox or open URL manually

Remote control stops

Network timeout or manual stop

Re-enable Allow Remote Control
