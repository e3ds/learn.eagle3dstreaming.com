This guide explains how to seamlessly embed a Pixel Streaming session inside your webpage using iFrame script. It also covers how to enable two-way communication between your Unreal Engine application and the parent webpage when running inside an iFrame.

You can follow these steps using plain HTML, but the same approach applies to any framework or frontend technology (React, Angular, Vue, etc.)
