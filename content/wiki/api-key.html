The API key is unique to each user account, with only one API key assigned per username.

Follow these steps to get the API key for your account:

Step 1. Sign in to Control Panel

Step 2. Navigate to the Developer Section

Step 3. Copy the API Key

Step 4. Generate a New API Key

Generating a new API key will invalidate the previous one

If you generate a new API key, it will affect the apps where you have used the previous API key. For example, the server will not connect because the API key has changed.
