Every way a session can end, and the message the platform sends with it. onRedirectingWithMessage delivers all of them, which is why it is the one callback worth building on.

How you receive these

One callback, whatever the reason: 

e3ds_controller.callbacks.onRedirectingWithMessage = function (message) {
    showMyEndScreen(message);   // one screen, every reason below
};

Show the message. Do not parse it. The wording is written for a person to read and it changes — some of these carry a duration, a machine name or a username spliced in, and new ones are added over time. Code that branches on the text will break on a wording change nobody thought of as breaking. If you need to react differently to different endings, ask us for a machine-readable code rather than matching strings.

Someone ended it deliberately

What happenedWhat the viewer is told
You kicked them from Utilities → Running Streaming Sessions in the Control Panel You have been kicked out
A meeting host closed the meeting, ending it for every guest Host's Streaming Closed
The kick is the one you can trigger yourself

Open Utilities, find the session, and press Kick Player. Your own SDK page receives onRedirectingWithMessage a moment later. That is the cheapest way to test your end-of-session screen against a real event rather than by calling the callback by hand.

These four are about your account, not your viewer — and they are shown to the viewer, who can do nothing about any of them and should probably not read them. If your app is public, this is the strongest reason to replace the default screen with your own: catch the message, log it for yourself, and show the visitor something that makes sense from where they are sitting.

This list will grow

Which is the argument for one screen, not a branch per message

New endings are added as the platform changes, and they arrive through the same callback with wording you have never seen. A page that shows whatever it is given handles them all on the day they appear. A page that matches known strings silently shows nothing for the one it does not recognise — and that is the case you will hear about from a customer rather than find yourself.
