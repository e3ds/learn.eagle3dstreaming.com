Whitelisting: making the stream look like yours

By default a stream carries Eagle 3D Streaming's visuals — our logo, our loading icons, our interface styling. Whitelisting replaces them with yours, from the Control Panel, without touching your Unreal project.

  • Your logo in place of ours.
  • Your loading background, icons and styling.
  • A stream that looks like part of your product rather than a service embedded in it.

This is worth doing before showing the stream to a customer. The default branding tells them who built the platform, which is rarely the message you are paying for.

Hosting the page

The page that embeds your stream is an ordinary web page, and any host will serve it. If you do not already have one, a static host is enough — there is no server-side code unless you have added some.

The quickest route is a drag-and-drop deploy. Netlify's Drop, or an equivalent, takes the folder containing your index.html and gives you a URL in a few seconds. No account setup, no build configuration, nothing to learn — which makes it a good way to show someone the page today and decide about real hosting later.

If your login or token logic runs on a server, a static host is not enough. Drag-and-drop hosting serves files; it does not run code. Keeping your API key out of the browser — which you should — means somewhere that can execute your token request. That is a different kind of hosting, and it is worth knowing before you build the page rather than after.
