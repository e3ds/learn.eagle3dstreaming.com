Upload the ZIP you packaged, then create a link that streams it. Nothing to install, and it works the same way for everyone on your team.

Before you begin

  • A ZIP of your packaged application, with the .exe at its top level — see Prepare your app in Unreal.
  • The Pixel Streaming plugin enabled before that package was built. A build made without it uploads perfectly and then will not stream.

Upload it

  1. Sign in and press Add Application

  2. Choose your ZIP

    Press Browse, or drag the file in. Only .zip is accepted — anything else is rejected with an Invalid File Type message rather than failing quietly later.

  3. Name it and press Upload

    A thumbnail is optional. So is Send Updates On Email, which mails you when the application is ready instead of making you watch the page — worth switching on for a large build.

  4. Wait for it to be prepared

    An estimate appears in the Control Panel. The upload is only the first part: the platform then unpacks the build and gets it onto a machine, so the wait continues after the file has finished transferring.

You will know it worked when

The application appears in your Control Panel and is no longer marked as preparing.

Stream it

  1. Create a stream link

    Open the application and press Create New Stream Link. This link is what you send to other people — anyone who opens it gets the stream, with no account of their own.

  2. Press Play App

  3. Wait for a machine

    A GPU machine is starting for your session.

  4. Press Play

    Browsers will not start audio and video on their own, so every stream waits for one click. This is a browser rule rather than a setting.

You will know it worked when

Your application is running in the browser and responding to your input.
