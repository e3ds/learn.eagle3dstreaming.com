Signing up takes about two minutes and finishes with you inside the Control Panel, which is where every app you stream is managed from.

Before you begin

  • An email address you can receive mail at. A one-time code is sent to it during sign-up, so an address you cannot open right now will stop you at step 5.

  1. Open the sign-up page

    Go to controlpanel.eagle3dstreaming.com/signup. Accounts are free to create, and nothing is charged until you choose a plan.

  2. Enter your email address

    Type the address and press Continue. Use an address you can open now — the code in step 5 goes to it.

  3. Choose a password

    Enter a password and press Continue.

  4. Choose a username

    Enter a username and press Continue. This name becomes part of the address of every app you publish, so it is visible to anyone you send a stream link to.

  5. Enter the code from your email

    A one-time code is sent to the address from step 2. Enter it and press Continue. If it has not arrived after a minute, check your spam folder before requesting another — a second request invalidates the first code.

You will know it worked when

The Control Panel opens. This is where you add applications, configure how they stream and get the links you share — you will return to it for everything that follows.

Your account starts with a demo application already in it, so there is something to stream before you have built anything.
