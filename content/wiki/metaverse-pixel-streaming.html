Metaverse Pixel Streaming follows the same Pixel Streaming workflow as Multiplayer Streaming.

Any Unreal Engine application built as a persistent, shared virtual world can be uploaded and streamed directly without additional configuration.

If your metaverse build supports:

  • Multiple concurrent users

  • Shared world state

it is compatible with Pixel Streaming on Eagle 3D Streaming.
