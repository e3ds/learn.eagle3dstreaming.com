Unreal can build a Linux version from a Windows machine, once you install the cross-compile toolchain. You do this once per engine version.

Before you begin

  • Unreal Engine installed through the Epic Games Launcher.
  • A project to build. A Third Person template is enough to try it.

Install the cross-compile toolchain

Unreal cannot produce a Linux build out of the box. The toolchain is an optional component of the engine install, and it must match the engine version you are building with.

  1. Open the Epic Games Launcher and go to Unreal Engine › Library

  2. Open the menu beside the engine version you will use

    The three-dot icon next to that version.

  3. Choose Options

    This opens the list of optional components for that install.

  4. Tick the Linux target platform and apply

    The download is large and the install takes a while. It only happens once per engine version — but note that installing a new engine version later means doing this again for it.

You will know it worked when

Unreal Editor offers Linux under Platforms. If it does not appear, the editor was open during the install — restart it.

Package the project

  1. Enable Pixel Streaming, and restart the editor

    In Edit › Plugins, search for Pixel Streaming, enable it, and restart. This matters more for Linux than for Windows: we do not stream-test Linux uploads, so a build without the plugin will upload happily and fail only when a user opens it.

  2. Go to Platforms › Linux › Package Project

    Choose an empty folder for the output.

  3. Wait, and read the log if it fails

    The first Linux package of a project is slow — shaders are compiled for a platform this project has never targeted before.

  4. Zip the contents of the output folder

    Select everything inside it — not the folder — and compress it to a ZIP. A Linux build has a .sh launcher at its root instead of an .exe, and the name of that file matters when you upload.

You now have

A ZIP with a .sh launcher at its top level. Note its name — the next page needs it.
