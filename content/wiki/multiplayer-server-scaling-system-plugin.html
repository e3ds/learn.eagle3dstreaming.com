When using a dedicated server for an Unreal Engine multiplayer Pixel Streaming application, the client application needs to connect to the multiplayer server when it starts.

Without this plugin, users need to manually provide the server IP address and port number to connect to the dedicated server. This can make the connection process inconvenient, especially when server instances are created dynamically.

The E3DS Multiplayer Server Scaling System Plugin simplifies this process by automatically connecting the client application to the appropriate multiplayer server.

With the plugin:

  • You don't need to manually enter the server IP address & the server port.

  • The application automatically receives the required server connection information.

  • The client automatically connects to the assigned multiplayer server when the application launches.

  • Users can play the multiplayer game directly from a mobile browser.

  • It is especially useful when multiplayer servers are dynamically scaled based on demand.

Supported Unreal Engine Versions

Unreal Engine 5.3 – 5.8

Download & Installation

You can download the E3DS Multiplayer Server Scaling System Plugin from the following sources:

  • Fab: E3DS Multiplayer Server Scaling System Plugin on Fab

  • GitHub: E3DS Multiplayer Server Scaling System Plugin on GitHub

Download the plugin and install it in your Unreal Engine project before proceeding with the configuration.
