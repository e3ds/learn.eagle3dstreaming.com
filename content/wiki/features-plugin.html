What the E3DS Features plugin's Blueprint nodes do — screenshots, URLs, file transfer, ending a session, device detection, fullscreen and mouse handling — and how to wire each one up.

All of these work the same way. Your app cannot reach the browser directly, so it sends a message to the streaming system, which acts on it in the page. The plugin is a Blueprint node per message, so you connect a node instead of constructing JSON.

Every page in this section assumes two things

The plugin is installed and enabled, and an instance of E3DS_PS_actor is in the level you are streaming. Without the actor the nodes compile and do nothing — which is the single most common reason a feature "does not work".

The features

FeatureWhat it does
ScreenshotsCaptures a frame at Unreal's own quality — not the stream's — and downloads it in the viewer's browser.
Open and redirect URLsOpens a link in a new tab, or sends the current tab somewhere else.
Ending a sessionStops the stream, or closes the viewer's tab, from inside the app.
File transferSends a file down to the viewer, or lets them upload one into the app.
Device detectionTells your app what the viewer is on, so it can adapt its interface.
Fullscreen and mouseGoes fullscreen, and switches between hovering and locked mouse.

Try them first

Every feature here is running in one demo app, keyed to the number row. Open it and press the keys before you build anything — it takes a minute and tells you what each one actually does.

Features plugin demo — also built per engine version: 5.3, 5.4, 5.5, 5.6, 5.7, 5.8.

Test in the remote editor, not in a packaged build. These features only do anything while streaming, so a packaged rebuild per change is a slow way to find a wiring mistake. Streaming the editor lets you edit the Blueprint and press the key in the same session.
