Two packages from one project: a server build with no graphics, and the game build players stream. The server build is the one with a catch.

First: the engine you package with matters

The binary Unreal Engine from the Epic Launcher cannot package a dedicated server

It fails, and it fails with "Unknown Error" — which tells you nothing about the actual cause. If you have already hit that wall, this is why. You need a source build of the engine.

Epic binary (Launcher)Epic source (GitHub)E3DS source build
Packages a dedicated serverNoYesYes
You have to build the engine—Yes — around 50 GB to download and 350 GB of disk for UE 5.5No — it is pre-built
Hardware needed—16 GB RAM and an 8-core CPU, or the build takes a very long timeNothing special

Use the E3DS build unless you have a reason not to. Building Epic's source yourself is a legitimate route and gets the same result, but it is most of a day and several hundred gigabytes. The E3DS build is the same capability, already compiled: download it here.

Switching your project to it

  1. Extract the ZIP.

  2. Under Engine\Binaries\Win64, make a desktop shortcut to the Unreal Editor executable so you can launch this engine directly.

  3. Right-click your .uproject, choose Switch Unreal Engine version, and point it at the extracted folder.

  4. Open the project and let it regenerate.

Package the server build

  1. Edit → Project Settings → Packaging, search for list of maps, and add your map — ThirdPersonMap for the template.

  2. Set the build target to YourProjectNameServer.

  3. Platforms → Windows → Package Project, into an empty folder.

Package into an empty folder each time. Server and game builds go to separate folders, and packaging over an existing build leaves files from the previous one behind — which produces a package that looks complete and behaves strangely.

Package the game build

The same operation with the ordinary target. Make sure the Pixel Streaming plugin is enabled first — the game build is the one that streams, so it needs it; the server does not.

  1. Set the build target to YourProjectName.

  2. Platforms → Windows → Package Project, into a different empty folder.

You now have two packages

A server that runs headless and a game that streams. Before uploading either, it is worth running them together on your own machine — two clients connecting to one server proves the pair works while both are still in front of you.
