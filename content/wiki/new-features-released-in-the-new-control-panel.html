Enable Browser Microphone - (July 10, 2024) ✅

Feature Overview: The newly added Enable Browser Microphone option in the Eagle 3D Streaming Control Panel allows the application to receive captured microphone data directly from the user’s browser. This feature enhances user interaction while streaming, making it possible to utilize microphone input real time.

Location: This feature is accessible under the Advanced Options section within the UI tab of the configuration settings.

Key Capabilities:

  • Browser Integration: Users can enable or disable the microphone input captured from their browser, streamlining communication during live streams.

  • Privacy Control: By default, the feature is toggled off, ensuring that microphone access is only granted with user consent.

  • Use Case: Ideal for Microphone enabled Unreal Engine applications.

Impact: This addition simplifies the setup for users needing real-time audio communication directly through their browser.

More details are in this document.

Analytics - (September 30, 2024)

We’re excited to introduce the new Analytics feature in the Eagle 3D Streaming Control Panel, featuring an updated UI and enhanced UX for a more intuitive experience in managing your streaming data.

Key Features:

  • Redesigned UI: The interface now offers a clean, structured layout for session data, including:

    • App name

    • Video start/stop times

    • Session duration

    • Location (city/country)

    • Browser and OS details

    • Total sessions and total stream time displayed for quick insights

  • Dynamic Visual Insights:

    • Interactive bar and pie charts with a drop-down filter to select and visualize data by App Name, City, Country, Browser, or OS.

  • Advanced Filtering and Search:

    • Apply filters and search within the data table for targeted analysis.

  • CSV Export:

    • Export Analytics data to CSV for external analysis or reporting.

  • Improved Performance:

    • Faster data retrieval and real-time updates ensure users always have access to current insights.

This release delivers a user-friendly Analytics experience with enhanced UI, advanced filtering options, flexible data visualization, and seamless CSV export capabilities.

The Side Panel - (October 10, 2024)

We are excited to announce the addition of a Side Panel in the Eagle3D Streaming Control Panel. This new feature provides streamlined navigation and improved access to key tools such as UE Apps (which displays the apps layout and the Control Panel’s interface), our Flexible Plans, Analytics and a Logout option, all within a clean and intuitive interface.

Feature Highlights:

  • The Side Panel enhances the user experience by offering a consolidated view of the primary sections.

  • This update allows for quicker access to frequently used options while maintaining a clutter-free interface when collapsed.

This new feature also sets the foundation for future growth and the integration of new services as we continue to expand and improve the Eagle3D Streaming platform.
