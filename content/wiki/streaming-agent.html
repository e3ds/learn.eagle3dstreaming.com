The E3DS Streaming Agent lets you stream your Unreal applications from your own machine instead of ours. The app stays on your hardware; our platform handles the connection, the link and the session.

Worth doing when the app cannot leave your network, when you already own capable hardware, or when you want a machine reserved for one purpose. Otherwise, uploading to the platform is less work and less to maintain.

Before you begin

  • An Eagle 3D Streaming account, for the API key.
  • Windows 10, 11 or Server, with a GPU and a good internet connection.
  • 7-Zip, and the Unreal Engine prerequisites for the version you build with.
  • Disk space on C: — see the rule below, which is easy to underestimate.

Work out the disk space before you start. Apps are stored in C:\e3ds_streaming_apps, and you need:

zipped app size + extracted app size + the largest extracted app you already have

That third term is the one people miss. It is there because an update is unpacked alongside the existing copy before it replaces it — so the peak is higher than the steady state, and running out happens mid-update.

All GPUs are supported, but not all apps run on all of them. Some applications will not stream from an RTX 2080. If you are choosing hardware for this, test your actual app on it before committing.

Install it

  1. Install the prerequisites

    7-Zip, and the Unreal Engine prerequisites for your engine version (5.5 or 5.6). These are Epic's own redistributables, not ours.

  2. Put 7-Zip on the system PATH

    Control Panel › System and Security › System › Advanced system settings › Environment Variables. Edit Path, add a new entry for your 7-Zip folder — usually C:\Program Files\7-Zip — and press OK through every window.

    Then restart the machine. The agent will not find 7-Zip until you do.

  3. Extract the agent to your C: drive

    Download EL.zip from the Control Panel to C:\ and extract it there.

  4. Run it once to create its configuration

    Double-click EL.exe. It creates config_EL.json beside itself and that is all you need from this run — close it again.

  5. Put your API key in the configuration

    Get your API key from the Control Panel, open config_EL.json in a text editor, paste the key in, and save. This is what ties the machine to your account.

  6. Run it again, and wait

    A terminal window opens. Connecting to our system takes one to two minutes; you are finished when it prints Ready to serve pixel streaming.

You will know it worked when

Your machine appears by name in the Observer, confirming our system can see it. Until it does, the agent is running but not reachable, and a stream sent to it will wait for a machine that never answers.

Start it automatically with Windows

The agent does not install itself as a service. If the machine reboots overnight, nothing brings it back unless you arrange it — and the failure looks like a machine that is simply never available.

  1. Open Task Scheduler and create a task

  2. Trigger: At log on, for any user

  3. Action: run EL.exe, with "Start in" set to its folder

    The "Start in" path is required, not optional. Without it the agent starts in the wrong directory and cannot find config_EL.json — so it runs, and does nothing.
