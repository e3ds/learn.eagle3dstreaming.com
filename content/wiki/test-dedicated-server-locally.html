Run your dedicated server and two clients on one machine, and confirm they meet — before any of it goes near the platform.

Double-clicking the server looks like it did nothing. It didn't do nothing. The server has no window, so it starts silently and keeps running, holding memory and CPU. Check Task Manager → Details for BootstrapPackagedGame.exe and end it. Launching through a shortcut with -log, as below, avoids the problem entirely by giving you a console to watch.

Start the server

  1. Right-click YourProjectServer.exe and Create shortcut.

  2. Open the shortcut's Properties, and at the end of the Target field add a space and -log.

  3. Run the shortcut. A console window opens with the server's log.

Find the port

Read the listening port out of the log — usually 7777.

Do not assume 7777. If another server instance is already running — including one you started by double-clicking and forgot about — Unreal increments the port, and your client will try to connect to a server that is not there. The log is the authority.

Connect a client

  1. Run YourProject.exe and wait for the menu or play screen.

  2. Press ~ to open the in-game console.

  3. Type the connect command with the port from the log:

    open 127.0.0.1:7777

Then do it again in a second client instance, so two players are in the same session. If the game is fullscreen and you cannot reach the other window, the Windows key or Alt+Tab gets you out.

What success looks like

Both clients in the same session, seeing each other. That confirms the server accepts connections and replication works — which is what you want established before adding streaming, scaling and the platform on top.
