Package, compress and upload in one click, from inside the editor, instead of three manual steps and a browser upload.

The manual route is: package the project, zip the build, open the Control Panel, upload the zip. The Automation Tools plugin does all three from the Unreal toolbar — and compresses with 7-Zip rather than a plain zip, which makes a meaningfully smaller file to send.

The saving is repetition, not a single upload

Once is easy either way. It earns its place when you upload daily — every iteration is one click instead of a sequence with four places to forget a step.

Requires

Unreal Engine 5.2 to 5.6.

Install

Download from Fab or GitHub, then install it the same way as any project plugin — the folder goes in your project's Plugins folder and you enable it under Edit → Plugins.

Configure and upload

The plugin uploads on your behalf, so it needs credentials for your account. Uploading from Unreal covers the settings and the upload itself.

It uploads to a specific app and version. Point it at the right one before the first run — the click that saves you time also replaces a build without a second confirmation, so it is worth checking once that the target is what you think it is.
