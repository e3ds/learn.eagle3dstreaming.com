Learn to use the Settings Control Bar from the new Control Panel.

Overview

Enabling the Settings Control Bar Feature allows you to have the Gear icon displayed while streaming your App. By expanding it, you can use the Resolution, speaker or the Full screen Features during runtime.

Prerequisites

Make sure to :

  1. Have access to the Control Panel.

  2. Have an Eagle 3D’s User Account.

Instructions

Step 1. Sign In to your Control Panel

Login with your information.

Step 2. Select your App from the Control Panel

Step 3. Generate a Streaming Link

See : Generate a Streaming Link for your App.

Step 4. Create a Config

See : Create a Config for each Streaming Link.

Step 5. Edit the Config

See : Edit your Config.

Step 6. Enable “Advanced Options”

Step 7. Click Streaming UI

Step 8. Enable Settings Control Bar

This displays the Gear icon during runtime.

1. Click Save

2. Click Save (again)

Step 9. Run the App to check the feature

1. Click Play App

2. The Gear icon ⚙️ is displayed

3. Click on the Gear icon ⚙️ to expand it

4. Click the image icon 🖼️ to manipulate the resolution

Tweak the resolution from Low to Mid to High.

Understanding Streaming Quality from Settings Control Bar Color

High / Ultra Quality — Green

When the streaming quality is Ultra or High, the Settings Control Bar will appear green.

Medium Quality — Yellow

When the streaming quality is Medium, the Settings Control Bar will appear yellow.

Low Quality — Red

When the streaming quality is Low, the Settings Control Bar will appear red.

5. Click on the Speaker icon 🔊

Control the Volume from a scale of 0 to 10 (Click and Drag the cursor).

6. Click the Full Screen icon

* Go Full Screen on a Computer device

Tip : enable the Dynamic feature to set a Full Screen for your App and get rid of the black borders on both sides of the screen.

See how to set a Dynamic Feature in this document.

Tip : Press ESC to exit Full Screen Mode.

* Go Full screen on Mobile

- From the UI Config

This will hide the App URL showing in the Browser of your Mobile while streaming your App and allow you to go Full screen. (Check the Video below)

- From Blueprints

You can toggle the Full screen mode from Blueprints.

Refer to to be able to achieve the Full screen mode from Blueprints.

Summary :

Now you are able to enable the Settings Control Bar from the Streaming UI Config in the New Control Panel and get the Gear icon displayed on your streamed App.

You can also expand the Gear icon and use all the Features in there. (i.e. The resolution, speaker and Full screen features).

The Control Bar is available for all devices.

Now you are ready to explore the Settings Control Bar !
