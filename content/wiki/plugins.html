Four Unreal plugins from Eagle 3D Streaming. Each one removes work you would otherwise do by hand; none of them is required to stream.

PluginUse it whenUnreal
E3DS Features Your app needs to do something the browser side normally handles — take a screenshot, open a URL, end the session, detect the viewer's device. Gives you a Blueprint node per feature. 5.3 – 5.8
E3DS Automation Tools You package and upload often, and want it to be one click instead of package, compress, upload. 5.2 – 5.6
Unreal Editor Remote Control You want to drive the Unreal Editor itself from a browser, on a machine that is not in front of you. 5.3 – 5.8
Multiplayer Server Scaling You run a dedicated multiplayer server and do not want players typing IP addresses. 5.3 – 5.8

All four are free, and all four are optional. A packaged Unreal app with Epic's Pixel Streaming plugin enabled streams on its own. These exist because certain jobs — browser communication, uploading, server discovery — are tedious enough to be worth a plugin.
