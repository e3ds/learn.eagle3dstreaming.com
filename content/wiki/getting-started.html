This is the shortest path from a new account to your own Unreal application running in a browser. Following it end to end takes about half an hour, most of which is Unreal packaging your project while you wait.

Eagle 3D Streaming runs your application on a cloud machine with a real GPU and sends the picture to a browser as video. Your users need no download, no installation and no graphics card of their own — they open a link. What you upload is a packaged Windows build of your project; everything after that happens on Eagle 3D Streaming's GPU machines.

Start with something that already works

Before packaging anything of your own, stream a sample app we provide. It takes a few minutes, and it proves the whole chain — your account, the platform, your network and your browser — before your own build is part of the picture. If something is wrong at that point, it is wrong in a much smaller place.

Do this first

Create your account, then stream the sample app. Once you have seen a stream running, come back for your own application.

If you would rather see one before signing up, this is a live stream of that same demo: open the demo app.

Then bring your own application

Getting your own project streaming has two halves. First you prepare it in Unreal: enable the Pixel Streaming plugin, package it for Windows, and put the result in a ZIP file. Then you upload that ZIP — and there are two ways to do that.

Start here

Upload from the Control Panel

You package the project yourself and upload the ZIP through a web page. Nothing to install, and it works the same way for everyone on your team.

Upload from Unreal

A plugin packages and uploads in one action, without leaving the editor. Worth installing once you upload often enough that the manual steps become tedious.

Both produce exactly the same result. The plugin saves time; it does not unlock anything. Start with the Control Panel, and move to the plugin when the repetition costs you more than the setup would.

What you need

Before you begin

  • An email address you can receive mail at — signing up sends a one-time code.
  • Unreal Engine 5.1 or newer, if you intend to stream your own project. Earlier versions are not supported.
  • Visual Studio set up for Unreal development, which Unreal's own installation guide covers.
  • Disk space for a packaged build. A modest project produces a few gigabytes.

You do not need a powerful computer to stream — the rendering happens on Eagle 3D Streaming's GPU machines. You need one capable of running Unreal only because that is where you build your project.
