Information about how to select a version of your App to run it from the new Control Panel.

Prerequisites

Make sure to :

  1. Have access to the New Control Panel.

  2. Have an Eagle 3D’s User Account.

Instructions

Step 1. Sign In to your Control Panel

Login with your information.

Step 2. Select your App

You need to have at least one App Uploaded.

Step 3. Click on the Drop Down Menu

1. Select the version

Tip : Select ‘'Latest’' to automatically stream any latest version of your App.

See how to Stream your App.

Step 4. Run the App

You are running the version of the App you selected previously.

You cannot delete the latest version of your App (that is why the 'Delete’ feature next to the Version drop down menu is not available).

See this document to delete a Version of your App from the new Control Panel.

Now you know how to select a version of your App!

See how to Copy the Streaming URL.
