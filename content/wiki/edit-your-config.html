Information about how to edit your Config from the Control Panel.

Prerequisites

  1. Access to the Control Panel.

  2. Eagle 3D’s User Account.

  3. At least one App Uploaded.

Instructions

Step 1. Sign In to the Control Panel

Login with your information.

Step 2. Select your App

Step 3. Generate a Streaming Link

See : Generate a Streaming Link for your App.

Step 4. Create a Config

See : Create a Config for each Streaming Link.

Step 5. Edit the Config

1. Warning 🚫

The Default Config cannot be edited.

Enter a Config Name to be able to proceed. (Apply Step 4).

2. Click Edit Config

We have named the Config ‘Demo’ in this example.

3. That will open the Common Config features page

Advanced Options is for Advanced Config features.

4. Edit the Common Config features

See : Edit the Common Config features.

5. Edit the Advanced Options feature

See : Edit the Advanced Options features of your Config.
