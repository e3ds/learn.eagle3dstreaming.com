Learn to create a Config from the Control Panel.

Prerequisites

  1. Access to the Control Panel.

  2. Eagle 3D’s User Account.

  3. At least one App Uploaded.

Instructions

Step 1. Sign In to the Control Panel

Login with your information.

Step 2. Select your App

Step 3. Generate a Streaming Link for your App

Refer to this document.

Step 4. Add a new Config

1. Expand the Drop down menu

2. Click 'Add New Config'

3. Enter the name of your Config

No spaces are allowed in the Config Name.

4. Click 'Add'

5. Config Name saved

Every Streaming Link can have its own different Config.

See how to edit your Config.
