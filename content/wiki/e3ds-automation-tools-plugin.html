The E3DS Automation Tools Plugin simplifies the process of packaging and uploading your Unreal Engine Pixel Streaming application to the Eagle 3D Streaming platform.

Instead of manually packaging your project, compressing the build, and uploading it through the E3DS Control Panel, the plugin automates the entire process with a single click.

Why use E3DS Automation Tools?

  • Automatically packaging your Unreal Engine Pixel Streaming project,

  • Automatically compresses the package using 7-Zip, achieving higher compression rates than standard zipping

  • Automatically uploading the compressed build to Eagle 3D Streaming System.

All these things are done with just a single click and makes your overall process very smooth by taking the responsibility of uploading your project to the perfect place it should be.

Supported Unreal Engine Versions

Unreal Engine 5.2 – 5.6

Download

You can download the E3DS Automation Tools Plugin from the following sources:

Fab Marketplace: E3DS Automation Tools Plugin on Fab

GitHub: E3DS Automation Tools Plugin on GitHub

Installation

Follow the E3DS Automation Tools Installation Guide to install the plugin in your Unreal Engine project.

Configure and Upload Your Application

After installing the plugin, follow the Upload and Stream the App guide to configure the plugin and upload your application to Eagle 3D Streaming.

This guide explains how to configure the required settings and use the automation tools to package, compress, and upload your application.
