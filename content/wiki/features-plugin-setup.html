The E3DS Features plugin adds one Blueprint node per feature, so your app can talk to the browser without you writing the message-passing yourself. Here is how to install it.

Everything the plugin does is possible without it — by sending custom messages between page and app and handling them at both ends. The plugin is that work, already done, with a node in front of it.

Before you start

Unreal Engine 5.3 to 5.8, and Epic's Pixel Streaming plugin — the Features plugin will not load without it.

  1. Download it from Fab or GitHub.

  2. Put the E3DSFeatures folder in your project's Plugins folder, creating that folder at the project root if it does not exist yet. 

    YourProject/
├── Config/
├── Content/
├── Plugins/
│   └── E3DSFeatures/
└── YourProject.uproject

  3. Enable both plugins. Open the project, go to Edit → Plugins, and enable Pixel Streaming and E3DS Features. Restart when asked.

You now have the E3DS nodes

Right-click in any Blueprint graph and search for E3DS. If nothing comes up, the plugin is not enabled — check Edit → Plugins again and confirm the editor restarted.

What it gives you

  • Capture and download a screenshot
  • Open a URL in a new tab, or redirect the current one
  • End the streaming session
  • Send files to and from the viewer's device
  • Detect the viewer's device and platform
  • Toggle fullscreen, and switch mouse schemes
