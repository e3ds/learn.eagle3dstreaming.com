The Frontend SDK puts the stream directly in your page and handles the parts you would otherwise write yourself: token generation, authentication, the connection, and starting the stream.

The old SDK no longer works. Our streaming infrastructure was upgraded and the previous SDK is not compatible with it. Integrations still using it have stopped streaming, not degraded.

Nothing changes in your Unreal application. The work is entirely on the web side, which makes the move smaller than it sounds.

Before you begin

  • An app uploaded and streaming from the Control Panel.
  • Your Streaming API key — and read the warning below, because there is more than one kind of key.
  • Your username, and the app and configuration names exactly as the Control Panel shows them.

Start from the sample, not from scratch

Download the demo project, get it streaming your app, and only then move the pieces into your real application. It is a working integration, so anything that fails is your configuration rather than your code — a far smaller thing to debug than both at once.

There is a live version you can open before downloading anything.

Configure it

Everything you need to change is in tokenManager.js, which generates and manages the token that authorises a session.

FieldSet it to
streamingApiKeyYour Streaming API key.
clientUserNameYour username on the platform.
tokenExpiryDurationHow long a token stays valid.
domainconnector.eagle3dstreaming.com
appNameThe application to embed, named as in the Control Panel.
configurationNameWhich of its configurations to use.

There are two kinds of API key, and only one works here. Use the Streaming API key. The other looks identical, is for a different purpose, and fails at token generation with nothing that says "wrong sort of key".

Enterprise plans use a different domain. Replace connector.eagle3dstreaming.com with the custom domain provided to you. If you are not sure which applies, ask support rather than guessing — a wrong domain fails at connection time and looks like a network fault.

Moving it into your own application

Once the sample streams your app: load the SDK, and call e3ds_controller.main() with the token data. From there, send and receive data and control the stream.

Your API key should not reach the browser in production. The sample keeps it in a JavaScript file because it is a sample — anyone who opens developer tools can read it. In a real integration the token request belongs on your server, so the key stays there and the browser only ever receives a short-lived token.
