This section provides an overview of embedding an Unreal Engine Pixel Streaming session into your website using the Eagle 3D Streaming (E3DS) Frontend SDK. The SDK offers a secure and streamlined integration process, making it easy to connect your web application to an E3DS stream.

Want to jump straight into integration?

Follow the SDK Integration Guide to get started right away.

Why Use the Frontend SDK?

The E3DS SDK provides a secure and optimized integration layer for embedding your Unreal Pixel Streaming applications into any website.
It manages:

  • Secure token generation

  • Authentication

  • Connection handling

  • Stream initialization

  • Modern, production-ready embed workflow

This removes the need to manually handle browser scripts or low-level streaming logic.
