A configuration is a named set of settings attached to a stream link. It decides how your app behaves when someone opens that link — who can get in, how long they stay, what the interface offers, and what the stream looks like while it loads.

How the pieces fit

ThingWhat it is
ApplicationThe build you uploaded.
Stream linkA shareable URL that opens that app.
ConfigurationThe settings that link uses.

One app can have several links, each with its own configuration. That is the point of the arrangement, and it is what most people miss: you do not have to choose one set of settings for an app. A locked-down link for a client — password, expiry date, no developer tools — and an open one for your own testing, both pointing at the same build.

A change applies to new sessions only. Anyone already streaming keeps the configuration that was active when they started. If you change a setting and it appears to do nothing, check whether you are looking at a session that began before the change.

Creating, editing and deleting

All three live in the same place. Select your app, generate or open a stream link, and use the configuration dropdown beside it:

  • Add New Config in the dropdown, then name it. The name is how you will recognise it later — client-demo beats config2.
  • Edit Config opens the settings, split into common options and advanced ones.
  • The trash icon beside a configuration deletes it.

What you can configure

Session and access

Password, link expiry, session length, idle timeout, anonymised URLs.

Microphone

Whether viewers can speak to your app, and how their audio is captured.

Fullscreen button

Whether the control appears, and how it behaves on each device.

The remaining groups — the streaming interface, the loading screen, and the developer options — are being rewritten and are listed in the navigation on the left.

Advanced options are hidden until you enable them. Several settings, including the platform choice a Linux build needs, are not visible until Advanced Options is switched on in the configuration editor. If a setting you have read about is not there, that is usually why.
