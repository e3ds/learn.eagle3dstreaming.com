The Web SDK puts a cloud-rendered Unreal application directly in your page — not inside an iframe — and hands you JavaScript control of it. Start and stop sessions, send data to the application, react to what it sends back, change quality while it runs.

Three pages, in the order most people want them

1. Web SDK demo manual — a running demo you can open right now. No account, no key, nothing to download. Every control explained, and which SDK call is behind it.

2. Set up the Web SDK — get the source code, run it, and point it at your own application. Plain HTML and JavaScript: no build step, no framework, nothing to install.

3. Web SDK reference — every call and every callback. Not read end to end; searched when you need one answer.

When to choose it over the other two

Embedding compares all three methods topic by topic. The short version of why you would pick this one:

What it gives you
Streaming URL A link. Nothing to build, and nothing you control.
iframe The stream on your page, controlled by posting messages to the frame. Your page cannot reach inside it.
Web SDK The stream is part of your page. Direct JavaScript calls, and — the part that usually decides it — your server decides who is allowed to start one.

That last row is the real argument. With a link or an iframe, the link itself grants access and you cannot revoke it for one person. With the SDK a session starts from a short-lived token, so your backend chooses who gets one, when, and for which application — see keeping your API key off the browser.

What it is built on

The Web SDK is built on Epic's PixelStreamingInfrastructure frontend — the same library that ships with Unreal Engine — and adds the part that library has no concept of: finding a machine, launching your application on it, queueing, session tokens and expiry, and the callbacks around all of that.

If you already know PixelStreamingInfrastructure

The streaming underneath is the same, so what you know about the video, the data channel and the stats still applies. What is new is everything before the stream exists — which is most of what these pages are about.
