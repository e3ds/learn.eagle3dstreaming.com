What a viewer looks at while your app starts. Six elements can be replaced with your own artwork, or the whole screen can play a video.

Worth the effort: the loading screen is the first thing anyone sees, it is on screen for the longest single wait in the session, and by default it carries our branding rather than yours.

Where these settings live

Stream link › Edit Config › Advanced Options › Loading Screen. Advanced Options has to be switched on first — none of this is visible until it is.

What you can replace, and with what

ElementFormatMaximum sizeWhat it is
LogoPNG800 × 400Your mark on the loading screen.
Loading imageGIF600 × 200The animated element — a spinner, or an animated wordmark.
Play buttonPNG400 × 400The button a viewer presses to start.
Loading backgroundPNG128 × 128Behind the loading screen.
Queue backgroundPNG—Shown while waiting for a machine.
Title bar iconPNG40 × 40The icon in the browser tab.

The loading image must be a GIF, not a PNG. It is the one element with a different format requirement, because it is the one meant to move.

The 128 × 128 limit on the loading background is what the original documentation states, and it is small for a full-screen backdrop. If your artwork is rejected or scales oddly, confirm that figure with support rather than assuming your file is at fault.

Uploading once, reusing everywhere

Images go into an asset library on your account, not into a single configuration. Upload once and the same file is selectable from every configuration you have.

  1. Open the element you want to change, and press Add New

  2. Upload a file, or pick one already in the library

    Browse or drag the file in, press Upload, then Add Selection. If the list still looks empty after uploading, press Refresh List — it does not always update on its own, and that looks exactly like a failed upload.

  3. Save

    Like every configuration change, this affects new sessions only. Anyone already streaming keeps what they started with.

A video instead

The loading screen can play a video rather than show a still image — worth it when the wait is long enough that something moving holds attention better than a logo.

Videos are added to a list the same way. With more than one, Shuffle Videos picks one at random per session, so a repeat visitor does not watch the same clip every time.

The video must be a direct video file, not a page that plays one. A link to a video-sharing page will not play here. It shows nothing at all, with no error — which reads as a broken loading screen rather than a wrong link.
