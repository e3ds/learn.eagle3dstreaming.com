Follow the steps to install E3DS Automation Tools:

Step 1. Download E3DS Automation Tools from this URL

Step 2. Open your Unreal Engine project folder and create a “Plugins” folder inside your project folder.

If Plugins folder already existed then skip this step

Step 3. Extract the ZIP file inside the Plugins folder.

Rename the extracted folder as “E3DSAutomationTools” as shown in Figure 3.

Make sure the folder structure and the contents inside the “E3DSAutomationTools” are like Figure 4.

Troubleshooting

1. GitHub ZIP version issue

When a new update is made to the E3DS Automation Tools on the GitHub repository, it may take 4-5 minutes to prepare the ZIP version. To verify if a recent update has been made, you can check this GitHub repository .
