Keep an application running continuously on your streamer machine, so viewers connect to something already started instead of waiting for it to boot.

Normally a session starts your app when someone opens the link, and they wait through the launch. With preallocation the app is already running, and the first thing they wait for is the connection — a few seconds rather than the whole cold start.

Whether you want this

It is a trade, not an improvement. You are buying the wait time back by paying for a machine that runs whether or not anybody is watching.

Worth it

Turn it on when

A live demo or event where the first impression is the point; a public-facing experience people arrive at unprompted; anything used often enough that the machine is rarely idle anyway.

Leave it off when

Usage is occasional or bursty, or the app is one of several sharing a machine. You would be paying continuously for a wait that happens a few times a day.

The machine works even when nobody is connected. The GPU and CPU are occupied continuously, the cost is continuous, and the machine must be sized for a sustained load rather than an occasional one. Turn preallocation off when you no longer need it — an app left preallocated after an event goes on costing exactly as much as it did during it.

Configure it

  1. Add the preallocation settings to config_EL.json

    Five keys, naming which app to keep running and whose account it belongs to: 

    {
  "preAllocateApp_configurationName": "default",
  "preAllocateApp_name": "E3DSFeaturesTemplate",
  "preAllocateApp_owner": "demo",
  "preAllocateApps": true,
  "apiKey": "your_api_key_here"
}

    preAllocateApp_name is the application, and preAllocateApp_configurationName is which of its configurations to run — both as they appear in the Control Panel. Save the file.

  2. Launch EL.exe

    The agent starts the application immediately rather than waiting for a viewer, and keeps it running.

You will know it worked when

Opening the streaming URL connects in a few seconds, with no launch phase. If you still see the app starting, the agent did not pick up the configuration — check the app and owner names match the Control Panel exactly.

While it is running

  • Watch GPU and memory. A continuously running app shows leaks that a short session never would.
  • Size the machine for sustained load, not for a peak it touches occasionally.
  • Turn it off when the event ends. This is the step people forget, and it is the one with a monthly bill attached.
