Upload the Linux ZIP and stream it. Two things differ from a Windows upload, and both cause failures that do not explain themselves.

Before you begin

  • A packaged Linux ZIP with a .sh launcher at its top level — see Build a Linux package.
  • Or, to try the process without building, the sample ZIP.

1. Tell the configuration it is a Linux build

Do this first, and do not skip it. A Linux app whose configuration still says Windows will sit in the queue waiting for a machine that will never match it. The symptom is "stuck waiting for a machine" with no error at all — and it looks identical to being busy.

  1. Create a stream link, and open its configuration

  2. Press Edit Config, and turn on Advanced Options

    The platform setting is not visible until Advanced Options is enabled.

  3. In the Development tab, set Platform to "Linux UE Build for PS"

  4. Save

2. Upload the ZIP

The application name must match the .sh file at the root of your ZIP. If the launcher is MyProject.sh, name the application MyProject. This is the Linux equivalent of the .exe rule on Windows, and a mismatch fails at launch rather than at upload — well after the point where the cause is obvious.

  1. Sign in and press Add Application

  2. Browse for your ZIP

  3. Name it after the .sh file, then upload

  4. Wait for it to be prepared

3. Stream it

Press Play App. A Linux session goes through four stages, and it is worth knowing them because the wait is longer than on Windows.

StageWhat is happeningIf it stops here
Requesting a slot Finding capacity for your session. Usually brief. Persistent waiting means capacity, not configuration.
Waiting for a machine A Linux machine is being allocated and started. Check the platform setting above. A config still set to Windows waits here forever.
Launching the app Your build is downloaded to the machine and started. Longer for a large build — the whole ZIP is transferred.
Streaming Video is flowing. —
You will know it worked when

Your Linux build is running in the browser and responding to input.
