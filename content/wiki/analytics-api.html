Every streaming session in a date range — app, version, where the viewer was, when it started and stopped, and how long it ran.

Request

POST https://agw.eagle3dstreaming.com/api/v4/fb/user-data-by-range
{
  "start": "2026-06-01T00:00:00.000Z",
  "end":   "2026-06-15T00:00:00.000Z",
  "apiKey": "YOUR_PERSONAL_API_KEY",
  "uid":    "YOUR_ASSIGNED_UID"
}
ParameterTypeRequiredWhat it is
startstringYesStart of the range, ISO 8601 UTC.
endstringYesEnd of the range, ISO 8601 UTC.
apiKeystringYesYour API key.
uidstringYesYour Eagle user identifier. If you do not have it, ask support — it is not shown in the Control Panel.

Node.js

const axios = require("axios");

const API_URL = "https://agw.eagle3dstreaming.com/api/v4/fb/user-data-by-range";

const getUserDataByRange = async (uid, start, end, apiKey) => {
  try {
    const response = await axios.post(
      API_URL,
      { uid, start, end, apiKey },
      { headers: { "Content-Type": "application/json" } }
    );
    return response.data;
  } catch (error) {
    console.error("API Error:", error.response);
    throw error;
  }
};

FieldTypeWhat it is
appNamestringThe application streamed.

Two things that catch people out

You cannot ask for one application. The request has no app parameter — it returns everything in your account for the range, and you filter on appName yourself. On a busy account that is a large response for a small question, so ask for the narrowest date range you can use.

Records appear about 30 to 60 seconds after a session. A query run immediately after someone finishes streaming will legitimately not show them. If you are reconciling counts against something else, allow for that lag rather than treating it as missing data.

Where else this data lives

The same numbers, without writing any code, are in the Control Panel's Analytics section. The API is for putting them somewhere else — your own dashboard, a billing system, a customer-facing usage report.
