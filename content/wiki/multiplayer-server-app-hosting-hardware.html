Eagle 3D Streaming allows you to host your Multiplayer Server App for free on our shared multiplayer server machines.

Multiplayer Server App Hosting

You can upload your multiplayer server app and use it with your Pixel Streaming application. This is useful for testing, demos, and lightweight multiplayer use cases.

However, the free multiplayer server hosting uses shared infrastructure, so there are some important limitations.

Limitations

1. Shared Server Infrastructure

Free multiplayer server apps run on shared Eagle 3D Streaming machines.

This means multiple server apps may run on the same infrastructure. If your multiplayer server app requires high CPU, RAM, or network usage, it may not be suitable for the shared environment.


2. Servers Are Located in the USA

Our shared multiplayer server machines are located in the United States.

If your users are located far from the USA, such as in Asia, the Middle East, or other distant regions, they may experience higher latency or slower response time.


3. Physical Data Center Dependency

The free multiplayer server machines are physical machines located in our data center.

If there is a data center-level issue, such as power failure, hardware failure, or network outage, your multiplayer server app may not start or may become unavailable.

If the multiplayer server app is unavailable, users will not be able to join the multiplayer session until the server is running again.


4. Not Recommended for Heavy Server Apps

If your multiplayer server app requires high CPU, high RAM, or continuous heavy processing, the free shared server may not be the best option.

Heavy server apps can affect stability and may require dedicated resources.

Recommended Solution

If your multiplayer server app requires better reliability, lower latency, higher hardware resources, or dedicated hosting, we recommend using a dedicated multiplayer server setup.

This can be arranged through Eagle 3D Streaming support.

What You Should Do

If your multiplayer server app is lightweight and used for testing or demos, you can use the free shared multiplayer server hosting.

If your app requires production reliability, high resources, low latency, or a specific server region, please contact support for a dedicated setup.
