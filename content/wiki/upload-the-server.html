Since both the server and the app must be in sync for a multiplayer game to work properly, both need to be packaged and deployed together.

Follow the steps to upload the server:

Step 1. Open the folder that you have selected for packaging server build and navigate to WindowsServer folder

Step 2. Select all files and make a ZIP file of that

Step 3. Login to control panel

Step 4. Select Multiplayer Server Apps

Step 5. Click on Add Applications

Step 6. Browse the packaged server build ZIP file that was created in step 2

Step 7. Give the app name same as .exe file inside the root of ZIP

Step 8. Click Upload

Step 9. The server app is uploaded
