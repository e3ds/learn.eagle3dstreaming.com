Why Version Control?

  • If you enable version control, each time you upload a new version of your app, it will increment the version number. For example, if your latest app version was 3, uploading a new version will make it version 4.

  • If version control is not enabled, the newly uploaded version will simply replace the previous one without keeping track of past versions.

Follow these steps to get the API key for your account:

Step 1. Sign in to Control Panel

Step 2. Navigate to the Developer Section

Step 3. Navigate to Streaming Version Control tab

Step 4. Enable Version Control

Step 5. Click on Confirm button
