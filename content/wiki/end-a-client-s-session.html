Prerequisite:

Before proceeding, ensure you have downloaded and installed the E3DS Features Plugin in your Unreal Engine project. For detailed instructions, refer to:
Download and Install the E3DS Features Plugin

Part 1. Blueprint Logic for Ending a Client's Session

  1. Open the level you intend to stream.

  2. Ensure an instance of the E3DS_PS_actor is in your level.

  3. Open the Level Blueprint.

  4. In the Event Graph, right-click and search for the Keyboard 7 event to add it to the graph.

  5. Drag from the Pressed execution pin of the 7 key event and search for the Force End Tab node.

  6. Connect the nodes as shown below.

  7. Compile and Save the Blueprint.

Part 2. Verification

This section explains how to verify that the session disconnect command is working.

  1. Connect to your remote editor session in your web browser by following the steps in our How to test in remote editor streaming documentation. Click inside the editor viewport to ensure it has focus.

  2. Press the 7 key on your keyboard.

    • Expected Result: The browser tab you are using for the Pixel Streaming session will disconnect immediately.

This confirms that the Blueprint successfully sends the command to disconnect the client’s session that initiated the action.
