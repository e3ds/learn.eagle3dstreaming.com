Supported Unreal Engine Versions

Eagle 3D Streaming currently supports Unreal Engine 5.1 and later.

For the best compatibility, performance, and stability, we recommend building your applications with Unreal Engine 5.1 or newer.

VR Streaming Support Now Available!

We’re excited to announce that Eagle 3D Streaming now supports VR streaming.

Start streaming your VR apps today for next-level virtual experiences, fully compatible with major VR headsets!

Linux Streaming Support Is Live!

We’re also excited to share that Linux-based Unreal Engine applications are now streamable through our platform.
Upload your Linux builds, configure them easily, and start streaming — all with the same great performance you expect.

Multiplayer Support Now Available!

Eagle 3D Streaming now supports multiplayer Unreal Engine applications.

Deploy and stream multiplayer experiences with multiple users connected to the same session, enabling real-time collaboration, training, visualization, and interactive gameplay directly from the browser.
